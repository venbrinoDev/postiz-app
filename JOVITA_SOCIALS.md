# Jovita Socials

Jovita Socials is Jovita's social publishing and scheduling service. This branch starts from upstream Postiz `main` at commit `23f29c458ab3cd79d785c1c45ed9c9888d5005bf` (November 13, 2026) and is licensed under the GNU Affero General Public License v3.0. The upstream copyright and license notices remain in this repository.

## Jovita modifications

- Added Jovita Socials name, icon, wordmark, favicon, sign-in copy, page titles, and local legal links. The mark was refined from an original generated concept.
- Kept provider and scheduling behavior from the upstream application unless a change is separately documented.
- Kept the existing Jovita YouTube OAuth configuration limited to the three channel scopes already granted by the owner.

When this modified application is made available over a network, its corresponding source must be available to users under AGPL-3.0 section 13. The public source location should be added to the deployed application before launch.
